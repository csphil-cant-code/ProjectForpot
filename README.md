# ProjectForpot

Budget monitoring app project structure.

## Folder structure

- src/app/ – application entry points and app-level configuration
- src/components/layout/ – shared layout components
- src/components/dashboard/ – dashboard widgets and summary cards
- src/components/budgets/ – budget-related UI components
- src/components/transactions/ – transaction list and form components
- src/features/auth/ – login, signup, and auth flows
- src/features/accounts/ – account management logic
- src/features/budgets/ – budget planning and tracking features
- src/features/categories/ – category management and rules
- src/features/transactions/ – expense/income tracking feature logic
- src/features/reports/ – analytics and reporting screens
- src/services/api/ – API client and backend integrations
- src/services/storage/ – local persistence and cache services
- src/hooks/ – reusable custom hooks
- src/stores/ – state management stores
- src/types/ – TypeScript types and interfaces
- src/utils/ – shared helpers and formatting utilities
- src/lib/ – app libraries and third-party integration wrappers
- src/styles/ – theme, variables, and global styles
- public/ – static assets
- docs/ – documentation and design notes
- tests/unit/ – unit tests
- tests/integration/ – integration tests
- tests/e2e/ – end-to-end tests
- scripts/ – automation and maintenance scripts
- config/ – environment and app configuration
- .github/workflows/ – CI/CD workflows
